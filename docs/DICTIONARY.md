# Словарь: источники и сборка DAWG

## Пайплайн
1. **word-list** — текстовый файл, одно слово на строку (уже отфильтрованный список).
2. Сборка DAWG: `npm run build:dawg -- shared/dict/words.txt shared/dict/rus-nouns.dawg.json`
   (скрипт `shared/scripts/build-dawg.ts`): нормализация (нижний регистр, «ё» → «е»),
   дедупликация, сортировка, минимизация.
3. Клиент/сервер: `Dawg.deserialize(json)` → проверка `has()` за O(k), k — длина слова.

## Правила отбора слов (архитектурная спецификация)
Разрешены только нарицательные существительные в начальной форме (им.п., ед.ч.), а также:
- слова, существующие только во мн.ч. (весы, дрожжи, будни, каникулы);
- отглагольные, зафиксированные в академических словарях (лёжка, обжигание);
- субстантивированные прилагательные и причастия (бастующий, детская).

Запрещены: имена собственные, глаголы, прилагательные, уменьшительно-ласкательные
формы без самостоятельного словарного статуса, нецензурная лексика, сокращения и аббревиатуры.

## Источники (статус: базовый словарь внедрён)
- **Внедрено**: [Harrix/Russian-Nouns](https://github.com/Harrix/Russian-Nouns)
  (MIT License, © Sergienko Anton; на основе словаря Т. Ф. Ефремовой / ODict) →
  `client/public/dict/words.txt` — **49 312 существительных**.
- Пайплайн фильтрации: нормализация (строчные, «ё» → «е»), отбраковка не-кириллических
  записей, ненормативной и грубой лексики (подстроки/префиксы), служебных слов
  (местоимения, частицы, междометия), объединение с курируемым списком ~740 базовых
  слов и pluralia tantum. Детали — `client/public/dict/SOURCES.md`.
- Контур загрузки в клиенте: `client/src/dict/dictionary.ts` — fetch `words.txt` →
  `Dawg.fromWords()` при старте; если файл недоступен — встроенный dev-набор
  (`client/src/dict/devWords.ts`).
- **Следующие задачи**: сверка со словарём А. А. Зализняка (часть речи, начальная
  форма), расширение списка pluralia tantum.

## Толковый словарь (контур 2 — внедрён)
- По нажатию на ход в истории открывается толкование слова: клиент
  `client/src/dict/definitions.ts` — запрос к русскому Викисловарю
  (`https://ru.wiktionary.org/api/rest_v1/page/definition/{слово}`), лицензия CC BY-SA 4.0,
  атрибуция в интерфейсе, лимиты (≤4 толкований, ≤200 символов).
- Кэш в localStorage `balda.def.<слово>`; «слово отсутствует» кэшируется,
  сетевые сбои — нет; таймаут запроса 4 с; офлайн — «определение не найдено».
- Данные Викисловаря не коммитятся в репозиторий и не поставляются в бандле.

## Модерация (контур 3, этап 5)
Краудсорсинг жалоб: игроки помечают слово → очередь лингвистической проверки →
обновление word-list и пересборка DAWG без релиза клиента.
