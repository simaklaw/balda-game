# Словарь: источники и сборка DAWG

## Пайплайн
1. **word-list** — текстовый файл, одно слово на строку (уже отфильтрованный список).
2. Сборка DAWG: `npm run build:dawg -- shared/dict/words.txt shared/dict/rus-nouns.dawg.json`
   (скрипт `shared/scripts/build-dawg.ts`): нормализация (нижний регистр, «ё» → «е»),
   дедупликация, сортировка, минимизация.
3. Клиент/сервер: `Dawg.deserialize(json)` → проверка `has()` за O(k), k — длина слова.

## Правила отбора слов (архитектурная спецификация)
Разрешены только нарицательные существительные в начальной форме (им.п., ед.ч.), а также:
- слова, существующие только во мн.ч. (весы, дрожжи, будни, каникулы);
- отглагольные, зафиксированные в академических словарях (лёжка, обжигание);
- субстантивированные прилагательные и причастия (бастующий, детская).

Запрещены: имена собственные, глаголы, прилагательные, уменьшительно-ласкательные
формы без самостоятельного словарного статуса, нецензурная лексика, сокращения и аббревиатуры.

## Источники (статус: подбор источника — открытая задача этапа 1)
- **Грамматический словарь А. А. Зализняка** — основной кандидат: содержит часть речи
  и словоформы, что позволяет отфильтровать существительные им.п. ед.ч. программно.
- OpenCorpora / ODict — грамматическая разметка части речи.
- Открытые word-list'ы русского языка с подходящей лицензией.

## Толковый словарь (контур 2, этап 2+)
Отдельная база «слово → определение»; вызывается из истории ходов по клику на слово.

## Модерация (контур 3, этап 5)
Краудсорсинг жалоб: игроки помечают слово → очередь лингвистической проверки →
обновление word-list и пересборка DAWG без релиза клиента.
