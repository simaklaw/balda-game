# Словарь: источники и сборка DAWG

## Пайплайн (реальный)
1. Сырые данные (не в git): дамп OpenCorpora, заголовки Викисловаря. `tools/dict/extract_oc.py` и
   `extract_wikt.py` превращают их в компактные выжимки `tools/dict/sources/*` (коммитятся вместе с sha256 сырья).
2. `python3 tools/dict/build.py` — детерминированная сборка: выжимки + `blocklist.txt` + `allowlist.txt` →
   `client/public/dict/words.txt` (один файл), `MANIFEST.json`, `tools/dict/rejected.tsv` (очередь вычитки с причинами).
3. `python3 tools/dict/verify.py` пересобирает и сверяет sha256 (CI-джоба `dictionary`).
4. Клиент: `client/src/dict/dictionary.ts` — один fetch `dict/words.txt` → `Dawg.fromWords()` (Worker, fallback на main);
   порог «словарь усечён» = 90 % от `counts.total` из `dict/MANIFEST.json` (если манифест недоступен — 10 000).
   Если файл недоступен — встроенный dev-набор (`client/src/dict/devWords.ts`).
Предсобранного DAWG-ассета нет: замер на 67291 слов — сборка ≈ 340 мс на Node, а сериализованный DAWG (1,7 МБ)
больше исходного списка (1,27 МБ), поэтому скрипт `build-dawg.ts` удалён.

Числа (число слов, разбивка принятых/отклонённых) — только из `client/public/dict/MANIFEST.json`, здесь не дублируются.

## Правила отбора слов (архитектурная спецификация)
Разрешены только нарицательные существительные в начальной форме (им.п., ед.ч.), а также:
- слова, существующие только во мн.ч. (весы, дрожжи, будни, каникулы) — по граммеме `Pltm` OpenCorpora + ручной список;
- субстантивированные прилагательные и причастия (больной, учащийся, гардеробная) — только по явной вычитке (`allowlist.txt`).

Запрещены: имена собственные, глаголы, прилагательные, падежные формы и множественное число при наличии единственного,
сокращения и аббревиатуры, нецензурная лексика и оскорбительные этнонимы (блок-лист ТОЧНЫХ форм; подстроки запрещены —
они вырезали «алебарда», «колебание», «неблагодарность»).
Порядок решений и коды причин — docstring `tools/dict/build.py`.

## Как пересобрать
```bash
python3 -I tools/dict/extract_oc.py  /путь/к/dictionary.txt        # только при смене сырья
python3 -I tools/dict/extract_wikt.py /путь/к/russian_dictionary.txt
npm run dict:build && npm run dict:test && npm run dict:verify && npm run dict:kpi
```
Решения по спорным словам — только правкой `blocklist.txt` / `allowlist.txt` с комментарием-обоснованием.

## Толковый словарь (контур 2 — внедрён)
- По нажатию на ход в истории открывается толкование слова: клиент
  `client/src/dict/definitions.ts` — запрос к русскому Викисловарю
  (`https://ru.wiktionary.org/api/rest_v1/page/definition/{слово}`), лицензия CC BY-SA 4.0,
  атрибуция в интерфейсе, лимиты (≤4 толкований, ≤200 символов).
- Кэш в localStorage `balda.def.<слово>`; «слово отсутствует» кэшируется,
  сетевые сбои — нет; таймаут запроса 4 с; офлайн — «определение не найдено».
- Данные Викисловаря не коммитятся в репозиторий и не поставляются в бандле.

## Модерация (контур 3, этап 5)
Краудсорсинг жалоб: игроки помечают слово → очередь лингвистической проверки →
обновление word-list и пересборка DAWG без релиза клиента.
