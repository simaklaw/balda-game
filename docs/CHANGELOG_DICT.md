# Журнал изменений словаря

Формат: дефект → исправление → правило → тест.

## S0 — диагностика
- Дефект: подстрочный фильтр прежнего пайплайна вырезал обиходные слова. Канареечные слова: отсутствовало 3 из 26
  (`учеба`, `колебание`, `страхолюдина`); сравнение с исходным списком Harrix показало **105 вырезанных слов**
  (`алебарда`, `амеба`, `злоупотребление`, `неблагодарность`, `дебаты`, …).
- Исправление: словарь пересобран от исходных данных, без подстрочных фильтров.
- Тест: `tools/dict/canary.mjs`, `fixtures.canary.txt`, `test_pipeline.py::test_canary`.

## S1 — юридическая расчистка
- Дефект: ~21 МБ защищённых словарей-PDF в публичном репозитории и истории; нет лицензии данных; нет текста MIT Harrix.
- Исправление: PDF удалены из истории `main`, `*.pdf` в `.gitignore`; добавлены `LICENSES/`, `LICENSE-DATA`, `NOTICE.md`.
- Правило: `scripts/check-dist.mjs` падает, если в `dist` нет текстов лицензий.

## S2 — детерминированный пайплайн
- Дефект: невоспроизводимый словарь (LLM-перебор, ручные правки), «выдуманные» пути в документации.
- Исправление: `tools/dict/build.py` + выжимки источников + манифест; контур A — OpenCorpora, контур B — кандидаты Harrix
  с проверкой по OpenCorpora и Викисловарю; блок-лист по точным формам; ручная вычитка спорных (`allowlist.txt`).
- Тесты: `tools/dict/test_pipeline.py` (правила, канарейки, негатив, воспроизводимость), `verify.py`.

## S3 — интеграция
- Один файл словаря, один fetch: удалены `words-extra.txt` и `loadExtraWords()`.
- Порог «усечённого словаря» привязан к `MANIFEST.counts.total` (90 %).
- `build-dawg.ts` удалён по замеру (см. `docs/DICTIONARY.md`).
- Не сделано: общий `WORD_RE` в `shared/` (нужен прогон vitest), счётчики «достижимо при 3×3/5×5/7×7» в UI, удаление слов длины 2.

## S4 — KPI и CI
- `scripts/dict-kpi.mjs` (блокирующие метрики), CI-джоба `dictionary`, npm-скрипты `dict:*`.
- Не вычисляются: `coverage@5000`, `noise@20000` — нет частотного списка (честный warning, не заглушка).

## 2026-11-20 — OpenRussian, стартовые слова, толкования
- Добавлен источник **OpenRussian** (Badestrand/russian-dictionary, CC BY-SA 4.0) — только порядок записей как эвристика для стартовых слов и KPI покрытия; в используемом файле числовое поле частотности не подтверждено, слова из него в словарь автоматически не попадают.
- Дополнен allowlist словами из первых 5000 записей OpenRussian (coverage@5000 = 99,86 %); словарь на момент сборки: 67 302 слова.
- Стартовые слова: `tools/dict/start_words.py` → `shared/src/startWords.ts` (пулы 3/5/7 букв: 150/1200/600 частотных нарицательных существительных в ед.ч.; исключения — `start_exclude.txt`). Используются и на сервере, и в оффлайн-партии (вместо фиксированных «бал»/«балда»). Файл Wordle-Russian-Dictionary (mediahope, без лицензии) в репозиторий не включён — только идея.
- Толкования: нажатие на слово в истории (оффлайн) и на панель игроков (онлайн) открывает определение из Викисловаря (REST, кэш). В прилагаемых дампах текстов статей нет, поэтому оффлайн-определений из дампов собрать нельзя.

## 2026-11-20 — финальные исключения и лицензии
- По решению владельца точечно заблокированы `негр`, `негритянка`, `подонок`, `погань`, `мразь`, `ублюдок`; они удалены воспроизводимой пересборкой, блок-лист проверяется тестом. Словарь: 67 296 записей.
- Сохранён действующий бюджет словаря 1 400 KiB сырого файла и 300 KiB gzip: после исключений файл около 1 246 KiB (gzip около 257 KiB), KPI проходит; лимит оставляет умеренный запас для подтверждённых дополнений.
- В `LICENSE-DATA` и публичную копию включён полный официальный текст CC BY-SA 4.0. Для OpenCorpora отмечено неразрешённое противоречие карточки Kaggle (поле 4.0, описание ссылается на 3.0) и отсутствие подтверждения права загрузившего переоформить upstream-лицензию; не представлять это как установленный факт.
