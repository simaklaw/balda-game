## Чек-лист ручного QA
- Офлайн: партия 3×3/5×5/7×7, стартовое слово случайное, толкование по нажатию на слово в истории, пропуск, конец партии.
- Онлайн: поиск соперника, ход, отказ хода (сообщение понятно), толкование (панель игроков → слово), обрыв сети и возврат (окно 45 с), сдача, итог и рейтинг.
- Экран: портрет/ландшафт, узкие телефоны, безопасные области, контраст, размеры нажатия, reduced motion.
- Новый игрок без подсказок: начать партию, понять допустимый ход, прочитать результат.
