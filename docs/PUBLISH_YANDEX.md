# Публикация черновика в Яндекс Играх

Официальная инструкция: yandex.com/dev/games/doc/en/console/add-new-game
(«Upload a game» — 5 шагов). Ниже — как они ложатся на наш репозиторий.

## 1. Создать черновик

1. Зайти в [консоль разработчика Яндекс Игр](https://games.yandex.ru/console/)
   (нужен аккаунт Яндекса, в настройках консоли — данные разработчика).
2. «Создать игру» → черновик создаётся сразу, игра ещё не видна игрокам.

## 2. Загрузить архив сборки

```bash
npm ci || npm install
npm run build --workspace client   # vite build → client/dist/
cd client/dist && zip -r ../../balda-client.zip . && cd ../..
```

- В архив кладётся содержимое `client/dist/` (index.html в корне архива,
  без вложенной папки).
- Игра — чистая статика (Vite-сборка), сервер не нужен: мультиплеер
  хостится отдельно (см. docs/DEPLOY.md), оффлайн-режим и рейтинг
  работают без него.
- SDK `/sdk.js` отдаёт сама площадка Яндекса — в сборку ничего добавлять
  не нужно, `loadYandexSdk()` подключает его в рантайме.

## 3. Заполнить черновик

- Название «Балда», описание, категория (настольные/словесные).
- Иконки и обложки по требованиям консоли, скриншоты (можно из эмулятора
  размеров в консоли: телефон/планшет/десктоп).
- Язык — русский.

## 4. Хосты и распространение

- Разрешённые хосты не нужны: всё внешнее (Викисловарь) — обычные ссылки,
  запросов к сторонним API игра не делает.
- Страны распространения — по желанию (по умолчанию все).

## 5. Проверка и модерация

- В черновике есть тестовая ссылка — прогнать: запуск, `LoadingAPI.ready`
  (вызывается в `main.ts` после полной загрузки), межстраничная реклама
  между партиями, облачные сейвы (тема, локальный рейтинг) под разными
  аккаунтами.
- Отправить на модерацию. Типичные причины отказа: не вызван `ready()`,
  битые ссылки, расхождение скриншотов с игрой.

## Что уже сделано со стороны кода

- `LoadingAPI.ready()` — вызывается после загрузки словаря и первого экрана.
- Межстраничная реклама — `showFullscreenAdv` не чаще раза в 3 минуты.
- Облачное хранилище игрока — тема и локальный рейтинг (топ-10 оффлайн-партий).
- Определение площадки по URL/UA, при сбоях — тихий фолбэк на веб.

## Нативные лидерборды Яндекса (позже)
