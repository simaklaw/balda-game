# Архитектура «Совершенная Балда»

## Общий вид
```
[Единый HTML5-клиент (PixiJS)]
        │  drag-to-select, canvas-клавиатура, темы
        ▼
[SDK Abstraction Layer]  — адаптер платформ (автоопределение окружения)
        ├──► Yandex Games SDK
        ├──► VK Bridge (VK / OK)
        └──► Telegram WebApp API
        ▼ (WebSocket/WSS — с этапа 4)
[Node.js-сервер] — DAWG, authoritative server, комнаты, Эло, античит
```

## Принципы
1. **Логика отдельно от рендера.** `shared/` содержит правила, словарь и ИИ на чистом TypeScript без DOM/Canvas — тестируется юнит-тестами, используется и клиентом, и сервером.
2. **Authoritative server (этап 4).** Клиент передаёт только координаты новой буквы и путь слова; валидация, очки, таймеры — на сервере.
3. **SDK-изоляция.** Игровой код не знает о платформах: доступ к auth/рекламе/платежам/storage — через интерфейс `PlatformAdapter`.
4. **Отказ от системной клавиатуры.** Ввод буквы — кастомная canvas-клавиатура, масштабируемая под экран (решает проблему перекрытия поля).
5. **Честная монетизация.** Подсказки — только в тренировке с ИИ; в рейтинговых матчах — никогда. Косметика: темы поля, плитки, титулы.

## Словарь (трёхконтурная валидация)
- **Контур 1 — DAWG**: Directed Acyclic Word Graph, проверка слова за O(k) < 1 мс. Источник: Грамматический словарь Зализняка (нарицательные сущ., им.п., ед.ч.).
- **Исключения (разрешены)**: слова только во мн.ч. (весы, дрожжи); отглагольные (лёжка); субстантивированные (детская).
- **Запрещены**: имена собственные, глаголы, прилагательные, уменьшительные без словарного статуса, мат, аббревиатуры.
- **Контур 2** — толковый словарь (клик на слово в истории → определение).
- **Контур 3** — модерация/краудсорсинг: жалобы на слова → очередь проверки, обновление базы без релиза клиента.

## Игровые правила и комнаты
- Поля: 3×3 (блиц), 5×5 (классика), 7×7 (расширенная).
- Соседство: ортогональное; опция диагоналей.
- Таймеры: 2 мин/ход; блиц 1 мин / 30 сек; Фишер (1 мин + 5 сек/ход).
- 3 пропуска подряд → техническое поражение.
- Reconnect Window: 45 сек на восстановление сессии.
- Рейтинг: модифицированный Эло; фишки распределяются пропорционально весам мест.

## Античит (этап 5)
- Телеметрия ввода: боты дают одинаковые интервалы и мгновенные редкие слова; человек — паузы и «примерки».
- Поведенческие микро-проверки при аномальных сериях.
- Shadow Pool: подтверждённые боты играют между собой.
