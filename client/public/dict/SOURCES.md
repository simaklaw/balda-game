# Источники словаря

- **Основной источник**: [Harrix/Russian-Nouns](https://github.com/Harrix/Russian-Nouns) — список существительных русского языка (файл dist/russian_nouns.txt).
- **Лицензия источника**: MIT License (c) Sergienko Anton — https://github.com/Harrix/Russian-Nouns/blob/main/LICENSE
- **Первооснова данных**: толковый словарь Т. Ф. Ефремовой (через проект ODict).

## Внесённые изменения (базовый контур)

- нормализация: строчные буквы, е вместо ё;
- отфильтрованы слова длиннее 15 и короче 2 букв, не-кириллические записи;
- отфильтрована ненормативная и разговорно-грубая лексика (по подстрокам и префиксам);
- отфильтрованы местоимения, частицы, междометия и прочие служебные слова;
- добавлен курируемый список ~740 базовых существительных и pluralia tantum (весы, каникулы, дрожжи и т. п.).

## Расширение (ноябрь 2026)

Добавлены заголовочные **существительные** (им.п. ед.ч. / pluralia tantum), извлечённые из PDF в корне репозитория:

1. **Ожегов С. И., Шведова Н. Ю.** «Толковый словарь русского языка»
   (`189504-pdf-a823f67ce0df57b8218ecef8.pdf`) — заголовочные сущ. с пометой м./ж./ср./мн.
2. **Шагалова Е. Н.** «Самый новейший толковый словарь русского языка XXI века»
   (`430548-pdf-f430ff3d01421c0e0edd90a8.pdf`) — неологизмы (айфон, аккаунт, андроид и т. п.).

Правила отбора при слиянии:
- только кириллица, длина 2–15, «ё» → «е»;
- грамматика заголовка: м. / ж. / ср. / мн.;
- без дефисных композитов (совместимость с полем);
- отсев OCR-мусора и грубой лексики.

Итог: **51 409** слов. Правила валидации — в `docs/DICTIONARY.md`.

## Толкования слов

- **Источник**: [русский Викисловарь](https://ru.wiktionary.org) (REST API `api/rest_v1/page/definition/{слово}`).
- **Лицензия**: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ru);
  толкования не хранятся в репозитории — загружаются по требованию при нажатии
  на слово в истории ходов, в интерфейсе указывается атрибуция
  («Источник: Викисловарь (CC BY-SA)»).
- **Кэш**: результат (включая отрицательный) сохраняется в localStorage
  (`balda.def.<слово>`); сетевые сбои не кэшируются.
- Особенность: слова в игре нормализованы («е» вместо «ё»), поэтому при
  отсутствии страницы пробуется вариант с полным «ё» (ёжик, слёзы).
