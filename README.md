# Балда — мультиплатформенная HTML5-игра

Словесная игра «Балда» для публикации в **Яндекс Играх, ВКонтакте, Одноклассниках и Telegram Mini Apps**.

## Ключевые особенности
- **Честная игра**: никаких платных подсказок в рейтинговых матчах — только эрудиция.
- **Академический словарь**: на базе Грамматического словаря Зализняка; только нарицательные существительные в начальной форме. Валидация через **DAWG** (проверка слова < 1 мс).
- **Толковый словарь**: клик на слово в истории ходов → определение.
- **Современный UX**: PixiJS (Canvas, 60 FPS), жест drag-to-select, кастомная виртуальная клавиатура (без системных), тёмная/светлая темы, mobile-first.
- **Гибкие правила**: поля 3×3 / 5×5 / 7×7, опция диагоналей, таймеры (2 мин, блиц 30–60 сек, Фишер).

## Структура монорепозитория
```
client/   — HTML5-клиент (PixiJS + Vite + TypeScript)
server/   — мультиплеер-бэкенд (Node.js + WebSocket), этап 4
shared/   — игровая логика и словарь (DAWG) — общий код клиента и сервера
docs/     — архитектура и дорожная карта
```

## Дорожная карта
1. **MVP (этапы 0–3)**: ядро правил + словарь DAWG + ИИ-соперник + UI на PixiJS → релиз оффлайн-режима в Яндекс Играх.
2. **Мультиплеер (этап 4)**: authoritative server, комнаты, рейтинг Эло.
3. **Античит и монетизация (этап 5)**: телеметрия ввода, косметика, модерация словаря.
