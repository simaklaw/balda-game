# Балда — мультиплатформенная HTML5-игра

Словесная игра «Балда» для публикации в **Яндекс Играх, ВКонтакте, Одноклассниках и Telegram Mini Apps**.

## Ключевые особенности
- **Честная игра**: никаких платных подсказок в рейтинговых матчах — только эрудиция.
- **Академический словарь**: на базе Грамматического словаря Зализняка; только нарицательные существительные в начальной форме. Валидация через **DAWG** (проверка слова < 1 мс).
- **Толковый словарь**: клик на слово в истории ходов → определение.
- **Онлайн-режим**: авторитарный WS-сервер, быстрый матч и комнаты по коду, рейтинг Эло (K 40/26/18), фишки, reconnect-сессии, защита WSS (origin-check, лимиты соединений и флуда, maxPayload 16 KB).
- **Нативные лидерборды**: локальный топ результатов + топ площадки (Яндекс) в меню.
- **Современный UX**: PixiJS (Canvas, 60 FPS), жест drag-to-select, кастомная виртуальная клавиатура (без системных), тёмная/светлая темы, mobile-first.
- **Гибкие правила**: поля 3×3 / 5×5 / 7×7, опция диагоналей, таймеры (2 мин, блиц 30–60 сек, Фишер).

## Структура монорепозитория
```
client/   — HTML5-клиент (PixiJS + Vite + TypeScript)
server/   — мультиплеер-бэкенд (Node.js + WebSocket)
shared/   — игровая логика, античит и словарь (DAWG) — общий код клиента и сервера
docs/     — архитектура, деплой, публикация
```

## Онлайн-сервер

- `GET /health` — живость и состояние: `{ ok, words, dictSource, rooms, players }`.
- `GET /metrics` — счётчики и датчики в формате Prometheus (`balda_*`: соединения, сообщения, ходы, партии, ошибки; датчики: сокеты/комнаты/игроки).
- Smoke-тест в CI поднимает сервер и играет настоящую партию двумя WS-клиентами (включая проверку `/metrics`).
- Защита: строгий разбор протокола, origin-check (`ALLOWED_ORIGINS`), лимит соединений на IP, окно флуда; Docker-образ — non-root.

## Дорожная карта — закрыта

1. **MVP (этапы 0–3)** ✅: ядро правил + словарь DAWG + ИИ-соперник + UI на PixiJS.
2. **Мультиплеер (этап 4)** ✅: authoritative server, комнаты, рейтинг Эло, деплой (Docker + WSS за обратным прокси).
3. **Античит и монетизация (этап 5)** ✅: телеметрия ввода, Shadow Pool, косметика (темы, титулы, рамки).
4. **Аналитика и публикация (этап 6)** ✅: платформенные адаптеры (Яндекс/VK/OK/Telegram), A/B-тесты, docs/PUBLISH_ALL.md.
5. **Hardening** ✅: строгий протокол, защита WSS, smoke в CI, метрики Prometheus, нативные лидерборды Яндекса.
